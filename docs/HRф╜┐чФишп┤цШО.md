# HR使用说明

适用对象：企业HR、招聘负责人、招聘顾问。

## 1. 注册与登录

1. 进入 `/hr/login.html`。
2. 老用户可使用密码登录或验证码登录。
3. 新用户可点击“手机号快捷登录/注册”，或进入注册页填写信息。
4. 首次使用需要完成邮箱验证、设置密码和HR实名认证。

## 2. 创建初面

1. 在“创建初面”填写岗位信息：公司名称、岗位名称、薪资范围、福利待遇、公司介绍、岗位职责、任职要求。
2. 在“面试问题”检查题目内容和题目数量，建议控制在1-13题。
3. 在“候选人预览”确认候选人看到的信息排版正确。
4. 在“生成链接”生成候选人专属面试链接和二维码。

## 3. 发送候选人链接

- 一条岗位链接可以发送给多个候选人。
- 候选人需要使用本人手机号登录，并完成实名认证与授权。
- 候选人完成面试后，HR可在“候选人列表”和“报告复核”查看状态。

## 4. 查看候选人和报告

- 候选人完成手机验证后，会出现在候选人列表。
- 候选人完成面试提交后，会生成面试记录和报告处理任务。
- 如果报告暂未生成，先确认候选人是否已经完整提交面试。

## 5. 注意事项

- 重新编辑岗位或题目后，应重新生成并发送最新链接。
- 不要把管理员页面或兑换码生成页面发给候选人。
- 如遇到验证码、实名、报告异常，先截图保留页面提示，再联系管理员排查。
