# 管理员运营说明

适用对象：内部运营、客服、管理员。

## 1. 免费月度会员活动

建议用“活动兑换码批次”发放50个个人月度会员名额。

推荐规则：

- 数量：50个
- 权益：个人月度会员
- 每码使用次数：1次
- 每个账号同批次最多兑换1次
- 有效期：7-15天
- 发放方式：添加企业微信后由客服人工发放

## 2. 发放流程

1. 管理员生成50个兑换码。
2. 客服在群内或小红书引流用户添加企业微信后发放。
3. 用户登录个人中心或会员页输入兑换码。
4. 系统开通个人月度会员权益。
5. 管理员查看兑换状态、使用账号和使用时间。

## 3. 客服话术

您好，感谢体验AI全量初面系统。这是您的个人月度会员兑换码：`XXXX-XXXX`。请登录系统后进入个人中心/会员页兑换。兑换码仅限本人使用，先到先得，有效期以页面提示为准。

## 4. 排查顺序

- 登录失败：检查手机号、邮箱、验证码、账号状态。
- 兑换失败：检查兑换码是否过期、是否已使用、该账号是否已兑换过。
- 面试提交失败：检查候选人会话、录音记录、材料表、报告状态。
- 报告不生成：检查录音、转写、报告处理任务。
