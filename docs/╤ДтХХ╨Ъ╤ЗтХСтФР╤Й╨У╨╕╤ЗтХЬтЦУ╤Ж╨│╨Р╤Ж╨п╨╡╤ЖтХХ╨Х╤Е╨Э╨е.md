# 上线部署检查清单

## 1. 基础配置

- 数据库结构和升级SQL已导入。
- 邮件发送配置已接通。
- 短信验证码配置已接通。
- 实名核身配置已接通。
- 对象存储或录音上传配置已接通。

## 2. HR端链路

- HR注册可完成。
- HR登录可完成。
- 邮箱验证可完成。
- 设置密码可完成。
- HR实名认证可完成。
- 创建初面四步流程可完成。
- 候选人链接和二维码可生成。
- 候选人列表可看到候选人状态。
- 报告复核页面可打开。

## 3. 候选人端链路

- 候选人打开邀请链接正常。
- 候选人手机号登录正常。
- 实名认证和授权正常。
- 简历上传正常。
- 设备检测正常。
- 语音面试可逐题回答。
- 面试提交后可进入完成页或处理页。
- 个人中心可查看面试记录。

## 4. 会员与兑换码

- 管理员可以生成兑换码。
- 用户可以兑换个人月度会员。
- 兑换码状态能记录未使用、已使用、使用账号、使用时间。
- 兑换码不可重复使用。

## 5. 上线后复测

- 使用新浏览器或无痕窗口重新跑完整HR链路。
- 使用新手机号或测试手机号重新跑完整候选人链路。
- 测试一个兑换码从发放到兑换成功的完整流程。
- 确认普通用户无法访问管理员生成入口。
