# 候选人使用说明

适用对象：收到HR面试邀请链接的求职者。

## 1. 进入面试

1. 打开HR发送的专属面试链接。
2. 使用本人手机号登录或注册。
3. 阅读并同意授权协议。
4. 完成实名认证。
5. 上传简历和必要材料。
6. 完成设备检测后开始语音初面。

## 2. 面试中注意事项

- 请保持网络稳定，不要频繁刷新页面。
- 请允许麦克风和摄像头权限。
- 摄像头仅用于本人在场检测，不向HR展示完整视频。
- 如果同一台手机换另一个候选人使用，请先退出登录，再重新打开面试链接。

## 3. 完成面试

- 回答完所有题目后，请点击提交。
- 提交成功后会进入完成页或处理页。
- 可进入个人中心查看自己的面试记录。

## 4. 异常处理

- 如果提示“缺少面试码”，请让HR重新发送完整邀请链接。
- 如果提示“请先登录”，请先用本人手机号登录。
- 如果提示“面试提交失败”，请不要反复点击，先联系HR或客服处理。
